# 设置：老师定制化

状态：已纳入新版设计，尚未实现。依据：2026-11-14 用户提供的八部分需求确认表。

## 入口与默认行为

- 入口：设置 → 老师定制化。沿用已选定的第 2 套浅色蓝白界面。
- 老师配置选择器默认选中“全能老师”，无需先填写确认表才能使用。
- “全能老师”适用于各学科，以当前题目、参考答案、满分和评分标准为依据；不使用写死的地理角色，不凭空添加教师未提供的扣分要求。
- 可以新建、命名、保存并选用专属老师配置；切回“全能老师”后，新任务不再套用此前专属老师的规则。
- 未完成或未保存的表单不会自动成为已启用配置。界面显示当前实际生效的配置。
- 切换或修改配置只影响后续任务；正在处理的一份答卷和历史记录保留当时的规则快照。

## 八部分确认表

### 1. 基本教学信息

任教学科、任教年级、教材版本、主要批改题型。

### 2. 批改范围

- 只判断最终答案，或同时批改答题过程。
- 单题、单题多个小问、整张试卷的批改范围说明。
- 手写、打印、两者混合。
- 公式、图形、表格、化学式等特殊内容。

确认表记录老师的期望范围；记录“整卷”不等于当前框选流程已自动具备整卷分题、逐小问定位填分能力。实现与验收须覆盖所启用的实际范围。

### 3. 评分要求

- 按得分点或整体评价给分。
- 同义表达、与参考答案不同的正确表达是否给分。
- 最终答案错误时的过程分规则。
- 错别字、拼写、语法、单位、格式的扣分规则。
- 是否允许小数分，最小计分单位。
- 一处错误只扣一次、同类错误扣分上限等特殊规则。
- 可按题型分别填写。

未填写的扣分条件保持“未指定”，不擅自设置默认扣分。模型结果需要验证分数范围与最小计分单位，不再从任意文本中取第一个整数。

### 4. 每道题的评分依据

题目完整内容、参考答案、满分、各小问满分、得分点及对应分值、扣分规则、其他可接受答案或解法。

- 主工作台允许老师换题时自行录入、修改；确认表中提供题目模板入口与填写说明。
- 老师长期评分习惯与当前题目数据分别保存，不把上一题答案当成所有题的通用标准。
- 当前题目的明确评分细则优先于老师的通用习惯；无法同时满足的分值、得分点或计分单位冲突在评分前显示给老师处理，不静默猜测。

### 5. 不确定情况处理

- 暂停批改，交老师确认。
- 显示建议分数及疑问，由老师确认。
- 其他处理规则。
- 空白答案、划掉后重写、多种答案并存的判分要求。

默认不确定时转人工确认；该状态优先于“自动填分”。识别失败、模型调用失败、加载中空白不能直接作为白卷给 0 分；答案短也不能直接判 0 分。

### 6. 结果展示

总分、简短扣分原因、逐得分点得分、原始识别文字、批改记录可见内容。

展示偏好只影响界面呈现，不取消用户已经要求的本地批改记录保存。

### 7. 阅卷平台与填分

平台名称与网址、电脑系统与浏览器、分数输入及回车行为、答案和输入框位置是否固定、操作演示材料。

项目当前约定：

- 目标平台为 https://school.nicezhuanye.com/，实际阅卷页加载信号尚未核实。
- “自动填分”默认不勾选。未勾选：评分后等老师确认，再填分、回车。勾选：正常结果自动填分、回车。
- 两种模式都在回车后 0.2 秒首次检查下一份，未就绪每隔 0.5 秒重试。
- 页面切换与加载是否完成要独立于答案内容判断；白色画面、OCR 无文字、网络暂时无请求均不足以单独认定已加载白卷。
- 无法确认新答卷已就绪时不得重复提交上一份，也不得把加载空白判 0 分；超时暂停提示。
- 停止、过期结果和重复点击不得触发后续自动填分。

### 8. 定制与验收材料

- 本地添加已人工评分的代表性样卷：满分、部分正确、错误、白卷、不同表达或解法、字迹不清及争议答案。
- 每份关联老师分数、给分点及扣分原因。
- 记录允许的分数偏差和必须转人工的情况；未明确前不宣称达到验收标准。
- 操作演示与样卷作为本地附件保存，不自动转为训练数据，也不自动发送给模型。
- 客户填写平时如何批改；程序根据选定配置构建识别与评分提示，无需客户编写提示词。

## 本地保存与生效规则

- 老师配置及其本地附件保存在用户于设置选择的记录目录中；保存路径不展示在主工作台。
- 本地保存与远程模型推理是不同环节：实际阅卷仍按用户选择的服务商调用模型，不宣称完全离线运行。
- 目录不可写、附件复制失败或配置保存失败时说明错误，不显示保存成功，也不启用半保存配置。
- 每份记录包含实际生效的老师配置、题目标准、识别和评分模型，以及建议分数、确认后分数与填分状态。
- API Key 不写入老师配置导出、日志、样卷或历史规则快照。

## 验收检查

1. 初次进入默认“全能老师”，不填写定制表也能按当前题目标准评分。
2. 选择专属配置后，其同义表达、过程分、小数分和特殊扣分规则进入该次评分上下文。
3. 切回“全能老师”不残留上一个专属老师的规则。
4. 改老师配置不影响已开始的任务和历史记录；换题不会误用上一题参考答案。
5. 识别不清或加载未完成，即使开启自动填分也不自动填 0 分。
6. 配置、附件和记录写入选择的本地目录，目录写入失败不得静默丢失记录。
7. 全科目下不再使用答案字符长度判 0 分，不擅自删除可能属于答案的数字或括号。
