阅卷台使用说明

运行环境
Windows 10/11 64 位，.NET Framework 4.6.2 或更高版本。
需要 Microsoft Edge WebView2 Runtime。
若提示缺少运行环境，请安装微软官方 Evergreen Runtime。
下载地址 https://developer.microsoft.com/microsoft-edge/webview2/

开始使用
1. 解压压缩包，双击“阅卷台.exe”。
2. 在设置中选择科目、填写模型 API Key，点击“保存模型配置”。
   API Key 加密保存在本机，后续启动自动载入。
3. 在阅卷工作台填写本题参考答案与评分标准。
4. 打开阅卷平台，框选学生答案区域，并点击平台的分数输入框。
5. 点击“AI 阅卷”。默认自动填分并回车切换下一份。
   取消“自动填分”后，由老师确认填入并回车。
6. 点击“停止阅卷”可取消当前等待及后续操作。

需要联网访问模型服务；模型接口费用由使用者的 API 账户承担。
OCR 固定使用 qwen-vl-ocr；评分模型可在设置中配置。
使用其他服务商评分时，需要另外填写百炼 OCR API Key。
